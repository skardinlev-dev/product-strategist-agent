# План проверки

У каждой ставки есть гипотеза, ожидаемое изменение, база сравнения, метод, срок, ответственный, вредный побочный эффект, критерий успеха и критерий провала.

Базу не выдумывать. Если замера не было, первый шаг плана — получить базу, а не «вырасти на 10%».

Учебная таблица не является результатом эксперимента. Ею можно проверить чувствительность формулы. Вывод о живых пользователях из неё не следует.

Условие пересмотра стратегии пишется заранее: какой факт отменит выбранный вариант.
