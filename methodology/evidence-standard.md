# Стандарт доказательств

Реестр — единственное место, где утверждение получает тип. В стратегии тип не повышается.

| Тип | Когда ставить |
| --- | --- |
| Verified Fact | Есть указанный источник, и утверждение в нём есть |
| Hypothesis | Проверяемое объяснение, данных ещё нет |
| Assumption | Условие, при котором работаем дальше |
| Estimate | Число, собранное из других чисел по названной формуле |
| Forecast | Будущее значение с названным методом |
| AI Inference | Вывод модели из уже записанных id |
| Unknown | Искали и не нашли |

Уверенность `high` ставится первичному документу по узкому утверждению. `medium` — пересказу и опросу с описанной выборкой. `low` — старому документу, который мог устареть, и вики. `n/a` — только у Unknown.

Учебный расчёт имеет происхождение `synthetic`. Он может быть Estimate, но не Verified Fact о компании.

Замена записи: старая получает `superseded` и в `note` id новой. Текст старой строки не стирается.
