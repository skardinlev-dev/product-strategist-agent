# Описание работы

## Назначение

Агент помогает руководителю цифрового продукта дойти от размытого запроса до двух согласованных стратегий и не теряет решение после паузы.

## Как устроено

Четыре слоя: правила, методика, материалы кейса, состояние. Подробности и список файлов — в `deliverables/architecture.md` и `README.md`.

## Модели и сервисы

Разбор собирался в Cursor. Имя модели и число токенов интерфейс сессии отдельно не отдал, поэтому конкретная модель и сумма в рублях здесь не указываются. Отдельные платные API не подключались. Поиск шёл по открытым страницам. Python-скрипты локальные и бесплатные.

## Промпты

Рабочие инструкции: `AGENTS.md`, `.cursor/rules/`, `.cursor/skills/*/SKILL.md`, `prompts/`. Они же являются ключевыми промптами. Отдельного скрытого промпта нет.

## Дополнительный уровень

Сделано: реестр с типами утверждений, трассировка `decision_trace.py`, учебные сценарии и чувствительность, модельный респондент с явной пометкой симуляции, хук начала сессии, навыки этапов, продолжение из файла состояния, пересмотр через статус `superseded` без стирания истории.

Не сделано: разбор живого интерфейса по скриншоту, аудио и видео, подключение MCP, отдельная модель-оценщик, замер «агент быстрее аналитика».

## Кейс

«МегаФон Плюс», открытые источники плюс учебный CSV. Решение: не звать новых людей и не обещать старую экономию, пока не проверены продажи и состав. Действующие периоды не обрывать. Start не закрывать.

## Время и расходы

Хронометраж отдельного прогона «с нуля в новом чате» не снимался: документы кейса собраны в рабочей сессии 20 ноября 2026. Расходы на модели сверх подписки Cursor не измерялись и поэтому не называются. Скрипты проверок стоят 0 ₽.

## Ошибки и участие человека

Два официальных текста МегаФона о продажах противоречат друг другу, и агент это не сгладил. Учебное подтверждение решения поставлено, чтобы показать закрытый контур. Для боевой задачи человек должен подтвердить выбор сам. Сеть до GitHub в ходе подготовки была нестабильна. Это не влияет на офлайн-проверки.

## Ограничения

Агент не знает маржу, базу и текущий состав. Модельный диалог не доказывает спрос. Файл `deliverables/demo-recording.mp4` — тихая запись экрана уже собранного кейса: файлы открываются по очереди, затем в терминале заново проходят проверки. Микрофона нет, и файл не показывает генерацию с пустого чата. Неудачный вызов `py`, которого нет в PATH этого терминала, из ролика убран; в кадре остаётся повтор тем же Python 3.12, которым проходят локальные проверки.
