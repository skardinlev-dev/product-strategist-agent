# Как показать проект

1. Откройте папку в Cursor.
2. Запустите проверки из `README.md`. Они должны закончиться без ошибок.
3. Откройте `demo/megafon-plus/00-project-brief.md`, затем реестр, затем `04-alternatives.md`, затем обе стратегии и план проверки.
4. Покажите `state/project-state.json`: этап 8, решение подтверждено учебно, следующие действия не пустые.
5. В новом чате вставьте текст из `prompts/resume.md`. Агент должен назвать текущий этап, а не писать бриф заново.
6. Для пересмотра запустите `python scripts/decision_trace.py --project demo/megafon-plus --impact E002`.

Снятый ролик: `deliverables/demo-recording.mp4`. Это тихий проход по файлам и проверки в терминале, без микрофона и без нового чата. План озвучки, если ролик будут переснимать: `deliverables/demo-video-script.md`.
