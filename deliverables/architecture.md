# Архитектура

Агент — это папка для Cursor. Модель читает правила, сама выбирает шаг, пишет артефакты и проверяет их скриптами. Отдельного сервера нет.

## Процесс

Восемь этапов в `methodology/workflow.md`. Постановка и выбор варианта ждут человека. Остальные этапы агент закрывает сам, если проверки проходят.

## Контекст

Постоянные правила (`AGENTS.md`, `.cursor/rules/`) не содержат кейс. Методика не содержит цифры МегаФона. Кейс лежит в `demo/megafon-plus`. Состояние — в `state/workspace.json` и в `demo/megafon-plus/state/`. Новый чат продолжает работу из JSON, а не из памяти прошлой беседы.

## Инструменты

Скрипты на стандартной библиотеке Python проверяют источники, баланс таблицы, структуру и трассировку решений. Хук `sessionStart` только напоминает прочитать состояние и пишет строку в `logs/session.log`. Навыки в `.cursor/skills/` — короткие процедуры этапов.

Модели-классификатора и MCP в этом репозитории нет. Поиск источников делался средствами среды разработки. Отдельный ключ поиска в проект не подключался.

## Что сознательно не сделано

Два параллельных хранилища не ведутся. Ранний набросок `tools/stratlib` удалён, чтобы не спорить с CSV-реестром. Автономный бот не запускается.
