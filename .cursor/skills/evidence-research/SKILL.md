# Исследование и реестр

1. Составь вопросы, ответ на которые может сменить вариант.
2. Открывай первичный источник раньше пересказа. Сохраняй URL и дату обращения в `sources.csv`.
3. Каждое существенное утверждение — строка `03-evidence-ledger.csv` с типом из `methodology/evidence-standard.md`.
4. Спор источников оставь двумя записями. Не усредняй.
5. Чего не нашёл, запиши типом Unknown и укажи, где искал.
6. Запусти `python scripts/validate_sources.py --project <проект>` и исправь ошибки скрипта.

Не создавай URL. Не повышай гипотезу до факта в соседнем абзаце.
