# Варианты

Собери не меньше трёх действий, которые нельзя выполнить одновременно. Обязательны «оставить как есть» и «закрыть или существенно сократить».

Для каждого: суть, сегмент, ценность, ресурсы, затраты, выгоды, риски, от чего зависит, какие доказательства нужны, когда вариант успешен, почему его стоит отклонить, что заставит вернуться.

Рекомендацию поставь только после сравнения по `methodology/decision-framework.md`. Не делай выбранный вариант заметным заранее заголовком «очевидный».

Деньги из учебной таблицы подписывай как учебные. Этап выбора оставь человеку.
