# План проверки

Для каждой ставки заполни гипотезу, ожидаемое изменение, базу, метод, срок, ответственного, побочный эффект, успех и провал.

Если базы нет, первым шагом поставь замер, а не целевой процент. Учебный CSV не подставляй вместо замера живых людей.

Условие пересмотра должно быть наблюдаемым фактом, а не «если станет хуже».
