# Продуктовая стратегия

Пиши только после статуса решения `confirmed`. Опирайся на `methodology/product-strategy-framework.md`.

Каждый вывод ссылается на `E###`. Отказы назови конкретно. Учебный вклад бери из `data/scenario.md`, не пересчитывай в уме.

Если решение человека расходится с твоей рекомендацией, стратегия следует за человеком, а расхождение запиши в журнал.
