# Продолжение после перерыва

Вставь в новый чат:

```text
Прочитай AGENTS.md, state/current-task.md и state/project-state.json активного проекта. Проверь последние артефакты и продолжи с незавершённого этапа. Не повторяй выполненные действия. Не считай прежние выводы окончательными, если появились новые данные или запись реестра больше не active.
```

Если пришли новые сведения, добавь:

```text
Новые сведения: <факт и ссылка>. Найди затронутые id через python scripts/decision_trace.py --project <проект> --impact <id>. Пометь устаревшее статусом superseded, не стирай. Напиши, нужно ли менять решение.
```
