# product-strategist-agent

Агент для руководителя цифрового продукта. Открывается в Cursor и доводит размытый запрос до продуктовой и коммуникационной стратегии с источниками, вариантами и планом проверки.

Собрано для MGIMO×AI Challenge, номинация «ИИ-проект», трек «Стратег Фабрики продуктов». Команда: Лев Скардин, Данила Козлов, Егор Гублин.

## Что нужно

- Cursor или другая среда, которая читает `AGENTS.md` и `.cursor/rules/`.
- Python 3.10 или новее. Внешние пакеты не нужны.
- Интернет только если агент открывает новые источники. Проверки и расчёты работают офлайн.
- Платный ключ в репозиторий класть не нужно. Отдельного API этот проект не вызывает.

Проверено на Python 3.12.10 в Windows. Git нужен только если вы сами коммитите. GitHub CLI нужен только для публикации.

## Первый запуск

1. Откройте эту папку в Cursor.
2. Начните новый чат и вставьте:

```text
Прочитай AGENTS.md и state/current-task.md. Продолжи активный проект с сохранённого места. Не начинай исследование заново.
```

3. Активный учебный проект уже указан в `state/workspace.json`: `demo/megafon-plus`.
4. Проверьте, что папка целая:

```text
python scripts/validate_project.py --repo
python scripts/validate_project.py --project demo/megafon-plus
python scripts/validate_sources.py --project demo/megafon-plus
python scripts/validate_data.py demo/megafon-plus/data/synthetic_metrics.csv
python scripts/scenario.py --project demo/megafon-plus
python -m unittest discover -s tests -v
```

На Windows, если команда `python` открывает магазин приложений, вызывайте `py -3` вместо `python`.

## Как остановить и продолжить

Состояние лежит в `demo/megafon-plus/state/project-state.json`. Закройте чат в любой момент. В новом чате используйте текст из `prompts/resume.md`. Агент не должен заново собирать уже записанные источники.

## Новая задача

Скопируйте `templates/project` в новую папку, поменяйте `state/workspace.json` и опишите запрос в `00-project-brief.md`. Демонстрационный кейс не переписывайте: он остаётся примером для жюри.

## Демонстрационный кейс

`demo/megafon-plus` — учебный разбор мультиподписки «МегаФон Плюс» на открытых источниках. Цифры базы, выручки и затрат в `data/synthetic_metrics.csv` выдуманы и помечены. Это не данные МегаФона.

## Что лежит в папке

| Папка | Роль |
| --- | --- |
| `.cursor/rules`, `AGENTS.md` | Постоянные правила |
| `.cursor/skills`, `prompts`, `methodology` | Повторяемые шаги и методика |
| `demo/megafon-plus` | Один законченный разбор |
| `scripts`, `tests` | Проверки и учебный расчёт |
| `state` | Какой проект сейчас активен |
| `deliverables` | Текст для сдачи и сценарий видео |

Запись экрана лежит в `deliverables/demo-recording.mp4`: тихий проход по уже собранным файлам, короче 10 минут, без микрофона и без генерации из пустого чата. В конце терминал заново прогоняет проверки проекта и источников и показывает, какие документы задевает запись E002. Текст в `deliverables/demo-video-script.md` — план озвучки, а не расшифровка этого файла.
