# Демонстрационный проект: МегаФон Плюс

Учебный разбор для жюри. Запрос руководителя выдуман: открытые источники не подтверждают, что компания поставила именно эту задачу.

## Почему этот продукт

Сравнивались три кандидата.

- «МегаФон Звук» как отдельный продукт в открытых материалах 2026 года не найден. Есть старые описания опции «МегаФон Музыка» и чужого сервиса «Звук». Стратегию строить не на чем.
- «МегаФон ТВ» в 2022 году уже менял условия бесплатного просмотра, а свежего продуктового контура в этом разборе мало. Конкурентное сравнение получилось бы про каталог, которого мы не смотрели.
- «МегаФон Плюс» запускался публично, у него есть ценовое уведомление 2026 года, архивная карточка, чужие мультиподписки для сравнения и явный пробел по составу. Этого достаточно для честного разбора и недостаточно для уверенной инвестиции. Поэтому выбран он.
