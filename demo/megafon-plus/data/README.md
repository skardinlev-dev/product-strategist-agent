# Учебный набор показателей

Данные созданы исключительно для демонстрации возможностей Product Strategist Agent. Они не получены от МегаФона, не являются внутренней статистикой компании и не отражают фактические показатели её продуктов.

Файл `synthetic_metrics.csv` собирает `scripts/build_synthetic_demo.py`. Повторить сборку: `python scripts/build_synthetic_demo.py`. Сценарный пересчёт: `python scripts/scenario.py --project demo/megafon-plus`.

## Что означает строка

Одна строка — один сегмент за один календарный месяц 2026 года. Сегменты:

- `megafon_balance` — учебные платящие, которым списание идёт со счёта телефона;
- `card_other_operator` — учебные платящие с оплатой картой;
- `tariff_included` — учебные пользователи, у которых подписка включена в тариф и прямая выручка равна нулю.

## Формулы

- `active_end = active_start + new_subscribers - churned`
- `revenue_rub` — рубли за месяц, округление средней базы `(active_start + active_end) / 2`, умноженной на `price_rub`
- у платных сегментов `partner_cost_rub = revenue_rub * 3 // 4` (допущение генератора, не договор с партнёром)
- у `tariff_included` `partner_cost_rub = active_end * 40` рублей на человека в месяц (тоже допущение)
- `active_users_share` — доля людей сегмента, которые в этом месяце открыли хотя бы один партнёрский сервис; на выручку в таблице не влияет
- цена платных сегментов в январе–мае 399 рублей за 30 дней, в июне 460; у включённых в тариф цена 0

Июньская цена подогнана к публичному уведомлению МегаФона от 4 июня 2026 только по порядку величины. Сами объёмы базы выдуманы.
